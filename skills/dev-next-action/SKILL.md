# dev-next-action

## 0. 前提

以下を確認する。

```sh
# ~/.claude/skills/dev-next-action は hatano299 リポジトリへの symlink
repo_root="$(dirname "$(dirname "$(readlink -f ~/.claude/skills/dev-next-action)")")"
```

- `$repo_root/docs/dev-strategy.md`
- `$repo_root/docs/dev-reference.md`
- `$repo_root/scripts/fin-issue/count`
   - count が `10` の場合、Issueの全工程を開発者が担当する。AIは実行をせず相談・レビューに徹する。

## 1. ステップの判断

セッション・作業ディレクトリの状態（test-list.mdの有無など）から、下記フェーズのどのステップにいるか判断する。
判断がつかない場合はユーザーに確認する。

### フェーズ1: テストリスト

1. [開発者] 作成する
2. [AI] レビューする
3. [開発者] 決定する

### フェーズ2: 1テストずつ（テストリストが空になるまで繰り返す）

1. [開発者] 次に書くテストを選ぶ
2. [開発者] 「最も重要なテスト」か判断する
3. [AI] 判断をレビューする
4. [開発者] 判断を決定する
5. [開発者 or AI] テストを実装する
   - 最も重要なテスト → 開発者が実装する
   - それ以外 → AI が実装する
6. [AI] テストを成功させる
7. [開発者] テスト成功を確認する
8. [開発者] リファクタリングの必要性を判断する
9. [AI] 判断をレビューする
10. [開発者] 判断を決定する
    - 不要 → 1 に戻る
    - 必要 → 11 へ
11. [開発者] リファクタリング方針を作成する
12. [AI] 方針をレビューする
13. [開発者] 方針を決定する
14. [AI] リファクタリングする
15. [開発者] リファクタリングをレビューする
16. [AI] リファクタリングを完了する
17. [開発者] コミットを指示する
18. [AI] コミットする
19. 1 に戻る（テストリストが空ならフェーズ3へ）

### フェーズ3: PR, ADR

1. [開発者] プッシュ、PR作成を指示する
2. [AI] プッシュ、PR作成(PRテンプレートに従う)を実行する
3. [開発者] PRの妥当性を説明する
4. [AI] 説明をレビューする
5. [開発者] 説明をPRにコメントする
6. [開発者] ADR作成要否を判断する
7. [AI] 判断をレビューする
8. [開発者] 判断を決定する
   - 不要 → 12 へ
   - 必要 → 9 へ
9. [AI] ADR を作成する
10. [開発者] ADR をレビューする
11. [AI] ADR をコミット、プッシュする
12. [開発者] PRを確認して問題なければマージする
    - マージ完了後、`fin` の実行を促す

### 想定外のエラーが起こった場合

TDDサイクルに組み込まれた新規テスト失敗ではなく、既存テスト失敗やランタイムエラーなど想定外のエラーが起きた場合、通常のステップを中断して以下を実行する。

1. [開発者] 原因の仮説を立てる
2. [AI] 仮説をレビューする
3. [開発者] 仮説を決定する
4. [AI] 仮説を検証する
5. [AI] 検証結果を伝える
   - 仮説が正しい → エラーを修正し、中断した元のステップに戻る
   - 仮説が正しくない → 分かったことを伝え、1 に戻る
6. [開発者] エラー修正を確認する

### 対象外

自動化・長期運用に耐えるシステム設計・困りごとの検討は月 1 振り返り時にチェックする。
本スキルでは厳密にチェックしない。

## 2. ネクストアクション出力

Now と Next を、次の形式で出力する。

| 区分 | ステップ | 担当者 | ステータス |
|---|---|---|---|
| Now | {内容} | 開発者 / AI | 未着手 / 進行中 / 完了 |
| Next | {内容} | 開発者 / AI | 未着手 / 進行中 / 完了 |

表の後に、ネクストアクションを文章で示す。対象は Now が未完了なら Now、完了していれば Next とする。

- 対象の担当が AI の場合：「〇〇を実行します」と出力し、続けて実行する
- 対象の担当が開発者の場合：「必要なアウトプット（〇〇を判断してください）」を示し、待機する
